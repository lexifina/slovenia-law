# 4. člen (kratice drugih zakonov)
V tem zakonu so uporabljene naslednje kratice drugih zakonov:
1. ZFK je Zakon o finančnih konglomeratih (Uradni list RS, št. 43/06),
2. ZGD-1 je Zakon o gospodarskih družbah (Uradni list RS, št. 42/06),
3. ZIN je Zakon o inšpekcijskem nadzoru (Uradni list RS, št. 56/02),
4. ZPlaP je Zakon o plačilnem prometu (Uradni list RS, št. 105/04 - uradno prečiščeno besedilo in 39/06),
5. ZUP je Zakon o splošnem upravnem postopku (Uradni list RS, št. 24/06 - uradno prečiščeno besedilo in 105/06 - ZUS-1),
6. ZUS-1 je Zakon o upravnem sporu (Uradni list RS, št. 105/06).
