# 111. člen (zaključek vpisanih izobraževanj pri Slovenskem inštitutu za revizijo)
Osebe, ki so vpisale izobraževanje pri Slovenskem inštitutu za revizijo za pridobitev strokovnega naziva pooblaščeni revizor do začetka veljavnosti tega zakona, lahko zaključijo program pod vpisnimi pogoji najkasneje do 31. decembra 2022.
