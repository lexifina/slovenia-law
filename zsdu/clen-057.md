# 57. člen

Način dela sveta delavcev se uredi s poslovnikom.

S poslovnikom se uredijo zlasti naslednja vprašanja:

- način sklicevanja sej,

- sklepčnost,

- način sprejemanja odločitev,

- vodenje zapisnika,

- sodelovanje oseb iz 61. člena tega zakona,

- način konstituiranja odborov sveta delavcev.
