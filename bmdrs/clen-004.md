# 4. člen Skladnost s politikami Evropske skupnosti

Pri izvajanju tega sporazuma Republika Slovenija spoštuje svoje obveznosti, ki izhajajo iz pravnega reda Evropske unije.

Projekti in dejavnosti, ki se financirajo po programu razvojne pomoči, so skladni s politikami Evropske unije, vključno s tistimi o varovanju okolja, enakosti med spoloma, prometu, čezevropskih omrežjih (TREN), konkurenci in javnih naročilih.
