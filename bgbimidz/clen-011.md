# 11. člen POSTOPEK SKUPNEGA DOGOVORA

1. Kadar med pogodbenikoma nastanejo težave ali dvomi o izvajanju ali razlagi sporazuma, si pristojna organa prizadevata rešiti zadevo s skupnim dogovorom.

2. Poleg dogovorov iz prvega odstavka se lahko pristojna organa pogodbenikov dogovorita o postopkih, ki se uporabljajo po 5., 6. in 9. členu.

3. Da bi pristojna organa pogodbenikov dosegla dogovor po tem členu, se lahko dogovarjata neposredno.

4. Pogodbenika se lahko dogovorita tudi o drugih oblikah reševanja sporov.
